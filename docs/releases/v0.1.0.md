# mojo-prometheus v0.1.0

## What it does
Prometheus metrics for Mojo with a `/metrics` text exposition byte-identical with prometheus_client.

## Highlights
- Counters, gauges, histograms, summaries with labels.
- `inc` in nanoseconds; exposition of 1,000 children in 3.8 ms against 79 ms in prometheus_client (pinned core, load 6.5).

## Changes
- First release.

## Verified
- `scripts/ci.sh` PASS on Mojo 1.2.0 and 1.3.0.dev2026110305: replay of a generated op script (validation, duplicates, bucket rules, NaN, wrong-kind calls) and float rows byte-identical with prometheus_client 0.26.0, each twice; 9/9 mutants.

## Known limits
- No `_created` series, Info, Enum, push gateway or HTTP server. Not thread-safe.

## Upgrade / run
- Add `mojo-prometheus` (pulls `mojo-pyformat`), then `from prometheus import Registry`. Try `examples/quickstart.mojo`.
